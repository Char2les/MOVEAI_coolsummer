# D3. 상품 상세설명 화면

## 화면 이름 / ID

* **화면 ID:** D3
* **화면 이름:** 상품 상세설명
* **서비스:** 코레일톡 쇼핑
* **화면 유형:** 상품 상세정보 확인 및 구매 옵션 선택 화면

---

# 1. 이 화면의 목적

D2 검색결과에서 사용자가 특정 상품을 선택했을 때 나타나는 **상품 상세설명 화면**을 구현한다.

이 화면에서 사용자는 단순히 상품 정보만 확인하는 것이 아니라 다음 내용을 한 번에 확인할 수 있어야 한다.

* 상품 이미지
* 판매 브랜드 / 매장
* 상품명
* 지역
* 가격
* 평점 및 리뷰
* 철도배송 관련 정보
* KTX특송 마감시간
* 상품 구성 옵션
* 추가 포장 옵션
* 구매 수량
* 실제 구매자 리뷰
* 코레일 배송 관련 안내
* 찜하기
* 장바구니
* 바로 구매

특히 일반 쇼핑몰 상품 상세페이지와 달리,

**“이 상품을 지금 주문하면 철도배송을 통해 언제 받을 수 있는지”**

가 사용자에게 명확하게 보여야 한다.

상품 정보와 **철도배송의 즉시성·편의성**을 동시에 보여주는 것이 D3의 핵심이다.

---

# 2. 진입 위치

## 기본 진입경로

**D2 검색결과**

→ 사용자가 원하는 상품 카드 클릭

→ **D3 상품 상세설명**

예시:

D2에서

**성심당 튀김소보로 10입 선물세트**

클릭

→ D3 진입

D2에서 선택한 상품의 `productId`를 기준으로 해당 상품정보를 표시한다.

실제 Backend API는 필요하지 않으며 Mock Data 또는 기존 Local State를 활용한다.

# 5. 화면 전체 구성 순서

D3는 **긴 세로 Scroll형 상품 상세페이지**로 구현한다.

위에서 아래 순서는 반드시 다음 구조를 따른다.

1. 상단 Navigation / 상품 이미지 영역
2. 상품 이미지 Carousel
3. 판매 브랜드 / 매장 카드
4. 지역 태그
5. 상품명
6. 평점 및 리뷰 요약
7. 가격
8. KTX특송 마감시간 안내
9. 상품 구성 선택
10. 추가 포장 옵션
11. 수량 선택
12. 리뷰 영역
13. 지역 리뷰 필터
14. 실제 리뷰 목록
15. 코레일 배송 옵션 안내
16. 하단 고정 구매 Action Bar

페이지 전체는 Vertical Scroll이 가능해야 한다.

---

# 6. 상단 상품 이미지 영역

화면 진입 시 가장 먼저 큰 상품 이미지가 보여야 한다.

Reference Image처럼 **상품 사진을 화면 상단의 가장 큰 시각 요소**로 구성한다.

### 포함 요소

상품 이미지 영역 상단 또는 위쪽에 다음 기능을 제공한다.

* 뒤로가기
* 홈
* 장바구니
* 찜하기

기존 프로젝트에서 사용하는 Icon Style을 유지한다.

---

# 7. 상품 이미지 Carousel

상품 이미지는 한 장만 고정해서 보여주는 것이 아니라 여러 장을 확인할 수 있는 **Carousel 형태**로 구현한다.

### 데모 기준

총 이미지:

**5장**

현재 이미지:

**1 / 5**

Reference Image처럼 이미지 영역 우측 하단에:

`1/5`

형태의 현재 위치 Indicator를 표시한다.

### 사용자 인터랙션

사용자가 좌우 Swipe:

→ 이전 / 다음 상품 이미지 표시

마지막 이미지에서 오른쪽 Swipe를 했을 때 오류가 발생하지 않도록 한다.

---

# 8. 상품 이미지 상단 태그

# 10. 브랜드 / 매장 카드 인터랙션

이 영역은 일반 상품 상세페이지와 코레일 쇼핑을 차별화하는 핵심 UI이다.

# 16. KTX특송 마감시간 동작

데모에서는 실제 실시간 열차 데이터 API가 필요하지 않다.

Mock Data로 다음 상태를 관리한다.

예:

* 출발시간: 14:00
* 현재 기준 남은시간: 30분

### 기본 데모

**14:00 출발 KTX특송 마감까지 30분 남았습니다**

표시

### 시간이 충분한 경우

일반 Blue 또는 Neutral 배송안내 형태를 사용할 수 있다.

### 마감이 임박한 경우

Reference Image처럼 Red/Pink 계열로 강조한다.

---

# 17. KTX특송 마감 예외상태

해당 회차의 접수가 마감된 경우:

**이번 KTX특송 접수가 마감되었습니다.**

보조문구:

**다음 이용 가능한 배송편을 확인해주세요.**

를 표시한다.

구매 자체를 완전히 막지 않고 다른 배송방식을 선택할 수 있도록 후속 주문 과정에서 처리할 수 있게 한다.

D3에서는 다음 배송편 상세 UI를 추가하지 않는다.

### 기본 수량

---

# 23. 수량 인터랙션

### `+`

수량 +1

### `-`

수량 -1

최소 수량:

**1**

따라서 수량 1에서 `-` 버튼을 눌러도 0으로 내려가지 않는다.

최대 수량은 데모 기준으로 10 정도로 설정할 수 있다.

최대수량 도달 시 `+` 버튼 비활성화.

# 24. 금액 계산

사용자가 선택한:

* 구성
* 추가 포장
* 수량

을 반영하여 주문 대상 금액을 계산한다.

예:

기본 세트 18,000원

* 개별포장 2,000원

× 수량 2

=

**40,000원**

실제 결제는 D3에서 수행하지 않는다.

선택값을 장바구니 또는 바로 구매 Flow로 전달한다.

# 28. 리뷰 카드

★★★★★

★★★★★

실제 회원정보는 필요하지 않다.

# 29. 리뷰 디자인

리뷰는 별도의 큰 Card를 반복하기보다 Reference Image처럼 **Divider를 이용한 간결한 세로 목록**으로 구성한다.

정보 강조 순서:

1. 사용자 및 지역
2. 별점
3. 리뷰 내용

리뷰 본문은 상품명이나 가격보다 시각적 강도가 낮아야 한다.

# 48. Option Card 디자인

`기본 세트 / 프리미엄 세트`는 작은 Radio Button만 사용하는 형태가 아니라 **클릭 가능한 넓은 Card** 형태로 만든다.

손가락으로 모바일에서 쉽게 누를 수 있는 크기로 구성한다.

Selected 상태가 명확해야 한다.

# 49. Fixed Bottom Action Bar 디자인

작은 Heart Button

중앙:

중간 크기 `장바구니`

오른쪽:

가장 강조된 `바로 구매`

크기 관계:

**바로 구매 ≥ 장바구니 > 찜하기**

하단 Bar가 본문 리뷰나 배송안내를 가리지 않도록 충분한 Bottom Padding을 추가한다.

# 50. 첨부된 Reference Image에서 반드시 유지해야 할 요소

첨부한 3개의 D3 Reference Image는 **한 상품 상세페이지를 Scroll 위치별로 캡처한 것**으로 이해한다.

세 이미지를 각각 다른 페이지로 만들지 않는다.

하나의 D3 세로 Scroll 화면으로 연결해서 구현한다.

반드시 다음 요소를 유지한다.

## 상품 이미지 영역

* 큰 상품 이미지
* `1/5` Carousel Indicator
* 보냉백 포장 Tag
* 전용 박스 Tag
* 상단 홈 / 장바구니 / 하트 관련 UI

## 매장 영역

* `성심당 대전역점`
* 브랜드 Logo 또는 매장 Icon
* `대전 대표 빵집 · 브랜드샵 바로가기`
* `이동 >`

## 상품 기본정보

* `대전` 지역 Tag
* `성심당 튀김소보로 10입 선물세트`
* ⭐ 4.7
* 리뷰 210
* `18,000원`

## 철도배송 정보

* `14:00 출발 KTX특송 마감까지 30분 남았습니다`
* 마감시간 Progress Bar

## 상품 옵션

* `구성 선택 (필수)`
* `기본 세트 18,000원`
* `프리미엄 세트 28,000원`

* `+2,000원`

## 리뷰

* `리뷰 210`
* `⭐ 4.7 평균`
* `나와 같은 지역 리뷰만 보기 (서울)`
* Toggle
* 실제 리뷰 List

## 배송 안내

* `코레일 배송 옵션 안내`

## 하단 구매영역

* Heart
* `장바구니`
* `바로 구매`
* Fixed Bottom Bar

* 장바구니 확인 → 담은 상품 확인 화면
* 바로 구매 → 기존 구매 진행 Flow
* 홈 → 기존 코레일톡 메인

특히 브랜드샵 화면, 담은 상품 화면, 결제 화면 등을 D3 작업 과정에서 새로 임의 설계하지 않는다.

기존 프로젝트에 해당 화면이 이미 있다면 route 연결만 한다.

**D3 구현에 필요한 상품 상세 UI, 옵션 상태관리, 리뷰, 장바구니 추가 동작 및 화면 연결만 수정한다.**
