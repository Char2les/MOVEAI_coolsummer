## 화면 이름 / ID

**배송 서비스 선택 / C2**

## 이 화면의 목적

고객이 배송정보를 입력한 뒤, **이용 가능한 배송 서비스의 예상 비용과 배송시간을 비교하고 원하는 배송 방법을 선택하는 화면**이다.

각 배송 옵션에는 서비스별 주요 정보와 함께 `최단시간`, `최적`, `최소비용` 등의 추천 기준을 표시하여 고객이 자신의 상황에 적합한 서비스를 쉽게 선택할 수 있도록 한다.

## 진입 위치

* C1. 고객 배송 주문 접수에서 고객이 수령인 및 배송지 정보를 입력하고 다음 단계로 진행하면 진입한다.
* 앞 단계에서 입력된 배송정보와 주문에 연결된 포장 규격 등을 기준으로 이용 가능한 배송 옵션과 예상 비용을 표시한다.

## 화면 구성 순서

1. 배송 서비스 선택 헤더
2. 필터 / 정렬 영역
3. 배송 서비스 옵션 목록
4. 선택한 옵션으로 진행하는 하단 버튼

배송 옵션이 한 화면을 초과할 경우 목록을 세로 스크롤할 수 있도록 한다.

## 각 UI 요소

### 배송 서비스 선택 헤더

* 뒤로가기 버튼
* 화면 제목 `배송 서비스 선택`

### 필터 / 정렬 영역

배송 서비스를 조건에 따라 확인할 수 있는 선택 영역이다.

Reference Image 기준 예시:

* `필터 전체`
* `정렬 추천순`

### 배송 서비스 옵션

이용 가능한 배송 서비스를 각각 하나의 선택 가능한 옵션으로 표시한다.

제공되는 배송 서비스:

* `KTX특송`
* `레일택배`
* `어전트서비스`
* `KTX특송 + 퀵서비스`

각 옵션에 표시되는 기본 정보:

* 배송 서비스명
* 예상 비용
* 예상 배송시간 또는 출발·도착 시간
* 필요한 경우 도착 방식 등 서비스 이용에 필요한 핵심 정보
* 해당 서비스의 추천 기준

추천 기준 예시:

* KTX특송: `최단시간`
* 레일택배: `최적`
* 어전트서비스: `최소비용`
* KTX특송 + 퀵서비스: 집까지 이어서 배송받을 수 있다는 편의성을 나타내는 기준

`KTX특송 + 퀵서비스`는 KTX특송 이용 후 퀵서비스를 연계하여 **고객이 입력한 최종 배송지까지 배송하는 옵션**이다.

### 옵션 선택

* 고객은 배송 옵션 중 하나를 선택한다.
* 한 번에 하나의 옵션만 선택할 수 있다.
* 현재 선택된 서비스가 무엇인지 명확하게 구분하여 표시한다.

### 하단 버튼

* `선택한 옵션으로 계속`
* 선택한 배송 서비스를 기준으로 다음 단계로 이동한다.

## 표시되는 문구 / 정보

* `배송 서비스 선택`
* `필터 전체`
* `정렬 추천순`
* `KTX특송`
* `레일택배`
* `어전트서비스`
* `KTX특송 + 퀵서비스`
* 서비스별 예상 비용
* 서비스별 예상 배송시간 또는 출발·도착 시간
* 서비스별 필요한 핵심 배송 정보
* `최단시간`
* `최적`
* `최소비용`
* KTX특송+퀵서비스의 편의성을 나타내는 추천 기준
* `선택한 옵션으로 계속`

## 비용 표시 기준

* 배송비는 서비스별 임의의 고정 가격이 아니라 **기존에 존재하는 규격별·거리별 가격 기준을 반영하는 것을 전제로 한다.**
* 이전 단계에서 연결된 포장 규격과 배송 구간 등의 정보가 비용 결정에 활용될 수 있다.
* 현재 실제 운임 계산 로직은 구현되어 있지 않으므로, 프로토타입에서는 실제 가격 체계를 참고한 **목업 가격 데이터**를 표시한다.

## Reference Image 기준

### 반드시 유지할 요소

* 여러 배송 서비스를 한 화면에서 비교하고 하나를 선택하는 구조
* `배송 서비스 선택` 헤더
* 필터 / 정렬 영역
* 각 배송 옵션에 서비스명, 예상 비용, 배송시간 등의 핵심 정보를 함께 표시하는 구조
* `최단시간`, `최적`, `최소비용`과 같이 서비스별 특징을 짧게 보여주는 방식
* 현재 선택된 배송 옵션이 구분되어 보이는 구조
* 하단의 `선택한 옵션으로 계속` 버튼

### Reference Image 대비 추가 / 변경 요소

* 기존 Reference Image의 `KTX특송`, `레일택배`, `어전트서비스`에 **`KTX특송 + 퀵서비스`**** 옵션을 추가**
* `KTX특송 + 퀵서비스`는 KTX특송 이후 퀵서비스를 연계하여 고객의 최종 배송지까지 배송하는 옵션으로 표시
* 배송 옵션이 4개로 증가하므로 필요한 경우 옵션 목록을 세로 스크롤할 수 있도록 구성
* 서비스별 비용은 실제 규격·거리별 가격 기준을 반영하는 것을 전제로 하되, 현재는 실제 계산 로직이 없으므로 목업 데이터를 사용

**디자인 및 세부 컴포넌트 스타일은 KORAIL+ Extension Design System을 따른다.**
