## 화면 이름 / ID

**배송 접수 확정 / C4**

## 이 화면의 목적

배송비 결제가 완료된 후, 고객에게 **철도배송 접수가 정상적으로 완료되었음을 안내하고 접수 결과를 확인할 수 있도록 하는 화면**이다.

고객은 배송 접수번호와 접수일시를 확인하고, 선택한 배송 서비스의 주요 내용을 다시 확인할 수 있다. 이후 `배송 조회`를 통해 배송 현황을 확인하거나 `홈으로` 이동할 수 있다.

## 진입 위치

* C3. 결제 화면에서 결제가 정상적으로 완료되면 자동으로 진입한다.
* 결제가 완료된 배송 건에 대해 접수번호가 생성되고, 해당 배송의 접수 완료 정보를 표시한다.

## 화면 구성 순서

1. 배송 접수 완료 안내
2. 접수 정보
3. 선택한 배송 서비스 정보
4. `배송 조회` 버튼
5. `홈으로` 버튼

## 각 UI 요소

### 배송 접수 완료 안내

화면 상단에서 배송 접수가 정상적으로 완료되었음을 명확하게 안내한다.

표시 문구 예시:

**`배송 접수가 확정되었습니다!`**

보조 문구:

`구매하신 상품을 안전하게 보내드릴게요.`

완료 상태를 직관적으로 인식할 수 있도록 체크 아이콘을 함께 표시한다.

### 접수 정보

완료된 배송 건을 식별하고 이후 조회할 수 있도록 기본 접수 정보를 표시한다.

표시 정보:

* `접수번호`
* `접수일시`

예시:

* 접수번호: `20260812-0004821`
* 접수일시: `2026.08.13 14:20`

접수번호는 이후 배송 조회 또는 고객 문의 시 해당 배송 건을 식별하는 정보로 사용한다.

### 선택한 배송 서비스 정보

고객이 신청한 배송 서비스를 최종적으로 다시 확인할 수 있는 영역이다.

C2와 C3에서 선택한 **KTX특송** 정보를 그대로 이어서 표시한다.

표시 정보:

* 배송 서비스명
* 배송 구간
* 예상 도착시간
* 수령 방식
* 결제금액

예시:

**선택한 배송 서비스**

**KTX특송**

`부산역 → 서울역`

`도착 예상　내일 09:00 ~ 12:00`

`수령 장소　서울역`

`결제금액　12,000원`

배송 서비스의 세부 조건을 다시 선택하거나 수정하는 기능은 제공하지 않고, **접수 완료 내용을 확인하는 용도**로만 표시한다.

### 배송 조회 버튼

* 문구: `배송 조회`
* 현재 접수된 배송 건의 배송 현황을 확인하는 화면으로 이동한다.
* 완료 화면에서 가장 주요한 후속 행동으로 제공한다.

### 홈으로 버튼

* 문구: `홈으로`
* 배송 접수 과정을 종료하고 서비스의 홈 화면으로 이동한다.
* `배송 조회`보다 보조적인 행동으로 제공한다.

## Reference Image 기준

### 반드시 유지할 요소

* 화면 상단에서 배송 접수 완료 상태를 명확하게 보여주는 구조
* 완료 체크 아이콘과 완료 메시지
* 접수번호 및 접수일시를 확인할 수 있는 영역
* 선택한 배송 서비스 정보를 다시 확인하는 영역
* 하단의 `배송 조회`, `홈으로` 두 가지 후속 행동
* `배송 조회`를 주요 행동으로 강조하는 구조

### Reference Image 대비 추가 / 변경 요소

* 선택한 배송 서비스 예시는 앞 단계와 동일하게 **KTX특송**으로 변경
* 배송 서비스 정보에 다음 내용을 표시

  * `KTX특송`
  * `부산역 → 서울역`
  * 예상 도착시간
  * `서울역`에서 수령
  * 결제금액 `12,000원`
* 완료 화면에서는 새로운 정보를 입력하거나 배송 옵션을 수정하는 기능은 제공하지 않음
* 접수 완료 이후 필요한 핵심 정보와 후속 행동만 제공하여 화면을 단순하게 유지

**디자인 및 세부 컴포넌트 스타일은 KORAIL+ Extension Design System을 따른다.**
