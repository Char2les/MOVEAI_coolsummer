## 화면 이름 / ID

**배송 조회 - 수령 장소 / C5-2**

## 이 화면의 목적

고객이 **선택한 배송 서비스의 상품을 어디에서, 어떻게 수령해야 하는지 확인하는 화면**이다.

본 프로토타입에서는 앞 단계에서 **KTX특송을 선택한 시나리오**를 예시로 사용하며, 상품이 서울역에 도착한 이후 고객이 KTX특송 수령 장소를 쉽게 찾고 상품을 수령할 수 있도록 역사 내부 위치와 수령 방법을 안내한다.

## 진입 위치

* C4. 배송 접수 확정 화면에서 `배송 조회` 버튼을 눌러 배송 조회 화면에 진입한다.
* 기본으로 표시되는 C5-1 `운행 현황` 화면에서 `수령 장소` 탭을 선택하면 C5-2 화면으로 전환된다.
* `운행 현황` 탭을 다시 선택하면 C5-1 화면으로 전환된다.

## 화면 구성 순서

1. 상단 헤더
2. 배송 열차 정보
3. `운행 현황 / 수령 장소` 탭
4. 수령 장소 기본 정보
5. 역사 내부 수령 위치 안내
6. 수령 방법 안내

## 각 UI 요소

### 상단 헤더

* 뒤로가기 버튼
* 화면 제목 `배송 조회`

### 배송 열차 정보

C5-1과 동일한 배송 열차 정보를 상단에 표시한다.

동일한 배송 건을 조회하는 화면이므로 탭을 전환하더라도 해당 정보는 유지한다.

KTX특송 예시:

`2026.08.20 (수)`

**KTX 005**

`부산역 09:00 → 서울역 11:42`

배송 상품이 도착한 상태의 예시에서는 `서울역 도착`과 같은 상태 정보도 함께 표시할 수 있다.

### 조회 탭

동일한 배송 건에 대해 다음 두 가지 정보를 전환하여 확인한다.

* `운행 현황`
* `수령 장소`

C5-2에서는 `수령 장소`가 선택된 상태로 표시한다.

### 수령 장소 기본 정보

도착역에서 상품을 수령해야 하는 장소의 핵심 정보를 텍스트로 먼저 안내한다.

KTX특송 예시:

**서울역 KTX특송 수령 장소**

* `위치　서울역 1층 맞이방, 3번 출구 인근`
* `운영시간　09:00 ~ 20:00`

구체적인 위치와 운영시간이 확정되지 않은 경우 프로토타입에서는 목업 정보를 사용한다.

### 역사 내부 수령 위치 안내

고객이 역사 내부에서 KTX특송 수령 장소를 직관적으로 찾을 수 있도록 **역사 평면도 또는 층별 안내도**를 표시한다.

Reference Image와 같이 서울역 1층의 주요 위치를 단순화하여 보여주고, 수령 장소를 명확한 위치 마커로 표시한다.

지도 내 표시 정보 예시:

* `1F`
* `맞이방`
* `3번 출구`
* `고객안내센터`
* `편의점`
* `카페`
* `KTX특송 수령 창구`

특히 `3번 출구`, `편의점` 등 고객이 실제로 위치를 찾을 때 활용할 수 있는 기준점을 함께 표시한다.

`KTX특송 수령 창구`는 다른 시설보다 명확하게 구분되는 위치 마커로 강조한다.

프로토타입에서는 실제 실내 길찾기나 지도 확대·축소 기능을 구현하지 않고, **정적인 역사 안내도 형태로 수령 위치만 확인할 수 있도록 한다.**

### 수령 방법 안내

지도 아래에 고객이 실제 상품을 수령하기 위해 해야 하는 행동을 간단한 순서로 안내한다.

KTX특송 예시:

**수령 방법**

1. `서울역 1층 맞이방 3번 출구 방향으로 이동해주세요.`
2. `편의점 옆 KTX특송 수령 창구에서 접수번호를 제시해주세요.`

수령 방법은 위치 설명만 제공하는 것이 아니라 **고객이 현장에서 무엇을 해야 하는지까지 이해할 수 있도록** 구성한다.

## Reference Image 기준

### 반드시 유지할 요소

* 상단의 `배송 조회` 헤더
* C5-1과 동일한 배송 열차 정보 요약 영역
* 운행 날짜, 열차번호, 출발역·도착역 및 시간을 보여주는 구조
* 배송 상태를 짧게 보여주는 방식
* `운행 현황 / 수령 장소` 두 개의 탭 구조
* `수령 장소`가 선택된 상태가 명확하게 보이는 구성
* `서울역 KTX특송 수령 장소`와 같이 수령 위치를 명확하게 안내하는 제목
* 위치와 운영시간을 텍스트로 먼저 안내하는 구조
* 역사 내부 평면도 또는 층별 안내도를 활용하여 수령 위치를 보여주는 구조
* 지도 안에서 `KTX특송 수령 창구`를 명확하게 강조하는 방식
* 지도 아래에 `수령 방법`을 단계별로 안내하는 구조

### Reference Image 대비 추가 / 변경 요소

* Reference Image는 **KTX특송 / 서울역 수령 시나리오의 예시 화면**으로 사용한다.
* 실제 서비스 구현 시 도착역에 따라 수령 장소명, 지도, 위치 설명 등이 변경될 수 있다.
* 지도는 실제 내비게이션 기능이 아닌 **수령 위치 안내를 위한 정적 평면도**로 구현한다.
* 확대·축소, 실시간 길찾기, 현재 사용자 위치 추적 등의 기능은 프로토타입에서 구현하지 않는다.
* 수령 시 필요한 행동은 `수령 방법` 영역에서 짧은 단계 형태로 안내한다.
* 역사 위치 및 운영시간이 확정되지 않은 경우 Reference Image의 내용은 목업 데이터로 사용한다.

**본 프로토타입의 화면 예시는 KTX특송을 선택한 경우를 기준으로 한다.**

**디자인 및 세부 컴포넌트 스타일은 KORAIL+ Extension Design System을 따른다.**
