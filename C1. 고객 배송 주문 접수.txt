## 화면 이름 / ID

**고객 배송 주문 접수 / C1**

## 이 화면의 목적

현장 제휴매장에서 상품을 구매한 고객이 **철도배송에 필요한 수령인 및 배송지 정보를 입력하고, 주문한 상품과 직원이 선택한 포장 규격을 확인하는 화면**이다.

고객은 배송 정보를 입력하고 현장에서 연결된 주문 정보를 확인한 뒤 다음 배송 접수 단계로 진행한다.

## 진입 위치

1. 고객이 제휴매장에서 상품을 주문하고 현장 결제를 진행한다.
2. 직원이 고객에게 철도배송 이용 여부를 안내한다.
3. 고객이 철도배송을 선택하면 직원이 주문 상품의 종류와 수량 등을 확인하고 **상품에 적합한 매장 포장 규격을 선택**한다.
4. 직원이 해당 주문과 연결된 배송 접수용 QR코드를 고객에게 제시한다.
5. 고객이 QR코드를 스캔하면 D1 화면으로 진입한다.
6. QR과 연결된 **주문 상품 정보와 직원이 선택한 포장 규격**이 자동으로 표시된다.

※ 직원이 선택한 매장 포장 규격과 실제 철도배송 규격을 연결하는 과정은 내부 로직으로 처리하며 고객 화면에는 노출하지 않는다.

## 화면 구성 순서

1. 상단 헤더
2. 받는 사람 정보 영역
3. 이름 입력
4. 연락처 입력
5. 배송지 입력
6. 상세주소 입력
7. 주문 및 포장 정보 확인 영역
8. `다음` 버튼

화면 내용이 한 화면을 넘어갈 경우 세로 스크롤이 가능하도록 한다.

## 각 UI 요소

### 상단 헤더

* 뒤로가기 버튼
* 화면 제목 `배송 주문 접수`

### 받는 사람 정보

* `받는 사람` 소제목
* 이름 입력 필드
* 연락처 입력 필드
* 배송지 입력 필드
* 상세주소 입력 필드

### 주문 및 포장 정보

QR을 통해 해당 주문과 연결된 정보를 보여주는 **확인용 영역**이며 고객이 직접 수정하지 않는다.

표시 정보:

* 주문 상품명
* 상품 수량
* 직원이 선택한 포장 규격

예시:

* `부산 어묵 선물세트 × 2`
* `포장 규격 · 중형 박스`

여러 상품을 구매한 경우 상품명과 수량을 각각 표시한다.

### 하단 버튼

* `다음`
* 필수 배송 정보를 입력한 후 다음 배송 접수 단계로 이동한다.

## 표시되는 문구 / 정보

* `배송 주문 접수`
* `받는 사람`
* `이름`
* `이름을 입력해주세요`
* `연락처`
* `010 - 0000 - 0000`
* `배송지`
* 선택된 기본 주소
* `상세주소`
* `상세주소를 입력해주세요`
* `주문 상품`
* 상품명 및 수량
* `포장 규격`
* 직원이 선택한 포장 규격
* `다음`

## Reference Image 기준

### 반드시 유지할 요소

* 상단의 뒤로가기 버튼과 `배송 주문 접수` 제목
* `받는 사람`을 기준으로 수령인 정보를 입력하는 구조
* `이름 → 연락처 → 배송지` 순서의 세로형 입력 흐름
* 화면 하단에 다음 단계로 이동하는 CTA가 배치되는 구조

### Reference Image 대비 추가 / 변경 요소

* `배송지` 아래에 **상세주소 입력 필드 추가**
* 수령인 정보 아래에 **주문 및 포장 정보 확인 영역 추가**
* 해당 영역에 **주문 상품명·수량과 직원이 선택한 포장 규격** 표시
* 주문 및 포장 정보는 고객이 수정할 수 없는 확인용 정보로 제공
* 매장 포장 규격과 실제 철도배송 규격의 변환 과정은 화면에 표시하지 않음
