## 화면 이름 / ID

**주문·배송 내역 / C7**

## 이 화면의 목적

고객이 **이전에 구매한 상품의 주문 정보와 해당 주문에 연결된 철도배송 정보를 다시 확인하는 화면**이다.

배송 접수 직후의 화면 흐름을 벗어난 이후에도 주문과 현재 배송 상태를 확인하고, 배송 중인 상품의 `배송 조회` 화면으로 다시 진입할 수 있도록 한다.

본 프로토타입에서는 **철도배송 옵션으로 KTX특송을 선택한 주문 건**을 대표 예시로 사용한다.

## 진입 위치

* **C6. 전체메뉴**의 `이동 · 편의 & 여행` 영역에서 `주문·배송 내역`을 선택하면 진입한다.
* 배송 신청 과정에서 바로 이어지는 화면이 아니라, 고객이 **기존 주문 및 배송 현황을 나중에 다시 확인하기 위한 재진입 화면**이다.
* 배송 중인 주문에서 `배송 조회`를 선택하면 **C5-1. 배송 조회 - 운행 현황** 화면으로 이동한다.

## 화면 구성 순서

1. 상단 헤더
2. 주문 기본 정보
3. 주문 상품 정보
4. 배송 정보
5. `배송 조회` 버튼

여러 주문이 있는 경우 주문 건별로 반복하여 확인할 수 있도록 구성한다.

프로토타입에서는 대표 주문 1건을 중심으로 구현한다.

## 각 UI 요소

### 상단 헤더

* 뒤로가기 버튼
* 화면 제목 `주문·배송 내역`

### 주문 기본 정보

해당 주문을 구분할 수 있는 기본 정보를 표시한다.

표시 정보:

* 주문일자
* 주문번호
* 주문 상태

예시:

`2026.08.13`

`주문번호 20260813-0004821`

`주문 완료`

### 주문 상품 정보

고객이 해당 주문에서 구매한 상품 정보를 표시한다.

표시 정보:

* 구매 매장
* 상품명
* 상품 수량
* 상품 결제금액

예시:

**삼진어묵 부산역점**

`부산 어묵 선물세트 × 2`

`상품 결제금액 40,000원`

여러 상품을 주문한 경우 상품별 이름과 수량을 함께 표시한다.

### 배송 정보

해당 주문에 철도배송이 연결되어 있는 경우 주문 상품 정보 아래에 배송 정보를 표시한다.

표시 정보:

* 선택한 배송 서비스
* 배송 구간
* 현재 배송 상태
* 배송비

KTX특송 예시:

**배송 정보**

`KTX특송`

`부산역 → 서울역`

`배송중`

`배송비 12,000원`

배송 상태는 실제 진행 상황에 따라 다음과 같이 변경할 수 있다.

* `출발 전`
* `배송중`
* `서울역 도착`
* `수령 완료`

상품 결제금액과 배송비는 서로 다른 결제이므로 각각 구분하여 표시한다.

### 배송 조회 버튼

배송 정보 하단에 `배송 조회` 버튼을 제공한다.

* 버튼 문구: `배송 조회`
* 선택하면 해당 배송 건의 **C5-1. 배송 조회 - 운행 현황**으로 이동한다.
* C5-1에서 `수령 장소`를 선택하면 C5-2 화면을 확인할 수 있다.

이를 통해 고객은 배송 접수 완료 화면을 벗어난 이후에도 주문·배송 내역에서 현재 배송 상황을 다시 확인할 수 있다.

## 표시되는 문구 / 정보

* `주문·배송 내역`
* 주문일자
* 주문번호
* 주문 상태
* 구매 매장명
* 상품명
* 상품 수량
* `상품 결제금액`
* `배송 정보`
* `KTX특송`
* `부산역 → 서울역`
* `출발 전` / `배송중` / `서울역 도착` / `수령 완료`
* `배송비`
* `배송 조회`

※ 주문번호, 상품 정보, 상품 결제금액, 배송비 및 배송 상태는 프로토타입용 목업 데이터를 사용할 수 있다.

## 신규 화면 구성 기준

* 별도의 Reference Image 없이 신규 화면으로 구성한다.
* 기존 KORAIL+의 내역형 화면과 공통 Design System을 기반으로 한다.
* 하나의 주문 건 안에서 **주문 상품 정보와 연결된 배송 정보를 함께 확인할 수 있도록 구성**한다.
* 상품 결제금액과 철도배송비는 별도 항목으로 구분한다.
* 철도배송이 연결된 주문에는 현재 배송 상태를 표시한다.
* 배송 현황을 확인할 필요가 있는 주문에는 `배송 조회` 버튼을 제공한다.
* `배송 조회` 선택 시 C5-1 배송 조회 화면으로 연결한다.
* 프로토타입에서는 KTX특송을 이용한 주문 1건을 대표 예시로 사용한다.

**디자인 및 세부 컴포넌트 스타일은 KORAIL+ Extension Design System을 따른다.**
