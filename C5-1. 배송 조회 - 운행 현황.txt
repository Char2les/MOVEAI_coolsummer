## 화면 이름 / ID

**배송 조회 - 운행 현황 / C5-1**

## 이 화면의 목적

고객이 **선택한 배송 서비스의 현재 이동 상태와 진행 현황을 확인하는 화면**이다.

본 프로토타입에서는 앞 단계에서 **KTX특송을 선택한 시나리오**를 예시로 사용하며, 배송 상품이 실린 KTX의 운행 정보와 현재 위치를 기준으로 배송 진행 상황을 보여준다.

고객은 어떤 열차로 상품이 이동하고 있는지, 현재 출발 전·이동 중·도착 중 어느 상태인지 확인할 수 있다.

## 진입 위치

* C4. 배송 접수 확정 화면에서 `배송 조회` 버튼을 누르면 진입한다.
* 배송 조회 화면의 기본 탭은 `운행 현황`으로 설정한다.
* `수령 장소` 탭을 선택하면 C5-2 화면으로 전환된다.

## 화면 구성 순서

1. 상단 헤더
2. 배송 열차 정보
3. 현재 배송 상태
4. `운행 현황 / 수령 장소` 탭
5. 열차 운행 현황
6. 현재 상태 안내 문구

## 각 UI 요소

### 상단 헤더

* 뒤로가기 버튼
* 화면 제목 `배송 조회`

### 배송 열차 정보

현재 배송 상품이 이동하는 열차의 핵심 정보를 요약하여 표시한다.

표시 정보:

* 운행 날짜
* 열차명 및 열차번호
* 출발역 및 출발시간
* 도착역 및 도착 예정시간

KTX특송 예시:

`2026.08.20 (수)`

**KTX 005**

`부산역 09:00 → 서울역 11:42`

### 현재 배송 상태

열차의 세부 운행정보를 확인하지 않아도 현재 배송 진행 상태를 바로 파악할 수 있도록 짧은 상태 정보를 표시한다.

상태 예시:

* `출발 전`
* `배송중 · 현재 대전역`
* `서울역 도착`

열차 운행 상태에 따라 표시 내용이 변경된다.

### 조회 탭

동일한 배송 건에 대해 다음 두 가지 정보를 전환하여 확인할 수 있다.

* `운행 현황`
* `수령 장소`

C5-1에서는 `운행 현황`이 선택된 상태로 표시한다.

### 열차 운행 현황

배송 상품이 실린 KTX의 운행 경로와 주요 정차역을 세로 형태로 표시한다.

각 정차역에는 다음 정보를 표시한다.

* 역명
* 도착 예정시간
* 출발 예정시간

화면 왼쪽에는 출발역부터 도착역까지 이어지는 세로형 운행 경로를 표시하고, **현재 열차 위치를 나타내는 마커 또는 아이콘**을 배치한다.

열차 운행 상태에 따라 마커 위치가 변경된다.

예시:

* 출발 전: 부산역 위치
* 운행 중: 현재 도착했거나 지나고 있는 역 또는 구간
* 도착 완료: 서울역 위치

프로토타입에서는 실제 열차 운행 데이터 연동 없이 상태별 목업 데이터를 사용한다.

### 현재 상태 안내 문구

운행 현황 하단에는 현재 배송 상태를 자연어로 안내한다.

상태별 예시:

출발 전
`아직 열차가 운행을 시작하지 않았어요.`

운행 중
`상품이 서울역으로 이동하고 있어요.`

도착 완료
`상품이 서울역에 도착했어요. 수령 장소를 확인해주세요.`

## 표시되는 문구 / 정보

* `배송 조회`
* `2026.08.20 (수)`
* `KTX 005`
* `부산역 09:00 → 서울역 11:42`
* `출발 전`
* `배송중`
* `서울역 도착`
* `운행 현황`
* `수령 장소`
* 주요 정차역
* 역별 도착·출발 예정시간
* 현재 상태 안내 문구

※ 열차번호, 운행시간, 정차역 및 현재 위치는 프로토타입용 목업 데이터로 사용할 수 있다.

## Reference Image 기준

### 반드시 유지할 요소

* 상단에서 배송 상품이 이용하는 열차 정보를 요약해서 보여주는 구조
* 운행 날짜, 열차번호, 출발역·도착역 및 시간을 확인할 수 있는 구조
* `운행 현황 / 수령 장소` 두 개의 탭을 전환하는 구조
* 주요 정차역을 위에서 아래로 보여주는 세로형 운행 현황
* 왼쪽 운행 경로와 현재 위치 마커를 통해 열차의 위치를 표현하는 방식
* 현재 배송 상태를 별도로 안내하는 구조

### Reference Image 대비 추가 / 변경 요소

* 기존 KORAIL+의 `시간표` 개념을 배송 관점의 **`운행 현황`으로 변경**
* 기존 `시간표 / 지도 / 운임·요금` 탭을 **`운행 현황 / 수령 장소` 2개 탭으로 변경**
* 단순 열차 운행정보가 아니라 **배송 상품의 이동 상황을 확인하는 용도**로 구성
* 현재 배송 상태를 `출발 전`, `배송중 · 현재 ○○역`, `도착` 등으로 별도 표시
* 열차 진행 상태에 따라 운행 경로상의 위치 마커가 이동하도록 표현
* 실제 실시간 데이터 연동은 구현하지 않고 프로토타입용 상태별 목업 데이터를 사용

**본 프로토타입의 화면 예시는 KTX특송을 선택한 경우를 기준으로 한다.**

**디자인 및 세부 컴포넌트 스타일은 KORAIL+ Extension Design System을 따른다.**
