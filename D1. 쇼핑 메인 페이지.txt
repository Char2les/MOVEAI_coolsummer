# D1. 쇼핑 메인 페이지 구현

현재 구현 중인 코레일 모바일 서비스에 **D1. 쇼핑 메인 페이지**를 구현해줘.

이 페이지는 코레일과 제휴한 지역 업체 및 지역 상품을 사용자가 탐색하고 구매할 수 있도록 연결하는 쇼핑 서비스의 메인 화면이다.

기존 코레일 메인 페이지에서 **‘쇼핑’ 아이콘을 클릭하면 이 화면으로 이동**하도록 연결해줘.

첨부한 두 개의 레퍼런스 이미지를 참고해줘.

* 첫 번째 D1 레퍼런스 이미지: 전체적인 쇼핑 메인 화면 구조 참고
* 두 번째 검색결과 레퍼런스 이미지: **상단 검색창 디자인 참고**

레퍼런스를 그대로 복제하기보다는 현재 프로젝트의 코레일 UI와 자연스럽게 연결되도록 구현해줘.

---

# 1. 전체 화면 구성

D1은 모바일 기준 세로 스크롤 페이지다.

화면의 정보 순서는 반드시 다음과 같이 구성해줘.

1. 쇼핑 페이지 상단 영역
2. **상품 검색창**
3. 지역별 / 상품별 / 테마별 탭
4. 최근 여행 기반 개인화 추천
5. 지금 인기 있는 지역상품
6. 지역별로 둘러보기
7. 테마 기획전
8. 기존 프로젝트의 하단 네비게이션

모바일 화면 약 360~430px 너비를 기준으로 구현해줘.

---

# 2. 상단 검색창 추가

D1 화면 상단에 **지역상품을 검색할 수 있는 검색창을 추가**해줘.

검색창 디자인은 첨부한 **검색결과 화면 레퍼런스 이미지의 검색창**을 참고한다.

단, D1에서는 검색결과 페이지에 있는 추천순, 가격순, 배송비순 등의 필터 버튼은 표시하지 않는다.

D1에서는 **검색창만 간결하게 노출**한다.

## 검색창 위치

다음 순서로 배치한다.

쇼핑 상단 영역
↓
**검색창**
↓
지역별 / 상품별 / 테마별 탭

즉, 검색창은 카테고리 탭보다 위에 있어야 한다.

---

# 3. 검색창 디자인

첨부된 검색결과 레퍼런스 이미지처럼

* 가로로 긴 rounded rectangle
* 흰색 배경
* 얇은 코레일 블루 계열 border
* 충분한 좌우 padding
* 왼쪽에 돋보기 아이콘
* 가운데 검색 입력 영역

형태로 구현한다.

검색창 높이는 약 44~48px 정도로 모바일에서 누르기 편하게 만들어줘.

검색창 안에는 기본값 대신 placeholder를 넣어줘.

예:

**지역명 또는 상품명을 검색해보세요**

또는 화면 너비가 좁다면

**지역·상품 검색**

으로 표시해도 된다.

검색창이 화면에서 지나치게 강조되기보다는 첨부한 검색결과 이미지처럼 깔끔하고 기능적인 형태로 구현해줘.

---

# 4. 검색 인터랙션

검색창은 단순한 디자인 요소가 아니라 실제로 동작해야 한다.

다음 동작을 구현해줘.

### 검색창 클릭

사용자가 검색창을 클릭하면 검색을 입력할 수 있게 한다.

기존 프로젝트 구조상 별도 검색 페이지를 사용하는 것이 자연스럽다면 검색 페이지로 이동시켜도 된다.

예:

`/shop/search`

### 검색어 입력

사용자가 다음과 같은 검색어를 입력할 수 있도록 한다.

* 대전
* 부산
* 어묵
* 쿠키
* 디저트
* 선물

### 검색 실행

검색창에서 Enter 또는 검색 아이콘을 누르면 해당 검색어에 맞는 상품 검색결과 화면으로 이동하도록 한다.

예:

`대전` 검색
→ 대전 지역 상품 검색결과

`어묵` 검색
→ 상품명 또는 카테고리에 어묵이 포함된 상품 검색결과

검색결과 페이지가 아직 구현되어 있지 않다면 우선 mock data를 활용한 간단한 검색결과 화면을 만들어 navigation이 실제로 작동하도록 해줘.

검색결과 화면의 UI는 첨부한 두 번째 검색결과 레퍼런스 이미지의 스타일을 참고할 수 있다.

---

# 5. 상단 카테고리 탭

검색창 바로 아래에 다음 3개의 탭을 동일한 너비로 배치한다.

**지역별 | 상품별 | 테마별**

D1에서는 기본적으로 **지역별**이 선택되어 있다.

선택된 탭은

* 글자 강조
* 하단에 코레일 블루 underline

으로 표시한다.

### 탭 클릭 동작

지역별 클릭
→ 지역 중심 쇼핑 콘텐츠

상품별 클릭
→ 상품 카테고리 중심 쇼핑 콘텐츠

테마별 클릭
→ 기획전 및 테마 중심 콘텐츠

로 실제 화면 콘텐츠가 변경되어야 한다.

탭 글자만 바뀌고 콘텐츠가 그대로 남는 형태로 만들지 말아줘.

---

# 6. 최근 여행 기반 개인화 추천

카테고리 탭 아래에는 사용자의 최근 코레일 이용 정보를 활용한 개인화 영역을 만든다.

D1 레퍼런스 이미지의

**“지난 부산 여행, 이어서 쇼핑할까요?”**

영역을 참고한다.

예:

### 지난 부산 여행, 이어서 쇼핑할까요?

보조 문구:

**여행의 기억을 지역 상품과 함께 이어가 보세요.**

영역 전체는 일반 흰 배경과 구별되는 **연한 블루 계열의 rounded card**로 구성한다.

내부에는 부산 관련 상품 또는 업체 약 2개를 표시한다.

예:

* 부산어묵 선물세트
* 부산 전통과자 세트

각 항목에는

* 이미지
* 상품 또는 업체명
* 간단한 설명

을 표시한다.

하단에는

**부산 상품 더 둘러보기 →**

버튼을 추가한다.

클릭하면 부산 지역 상품 리스트로 이동하도록 한다.

---

# 7. 지금 인기 있는 지역상품

다음 섹션 제목은

## 지금 인기 있는 지역상품

으로 한다.

오른쪽에는

**전체보기 >**

버튼을 배치한다.

상품들은 가로 스크롤 카드 리스트로 표시한다.

각 상품 카드에는 다음 요소가 포함되어야 한다.

* 상품 이미지
* 상품명
* 업체명 또는 지역명
* 가격
* 별점 또는 리뷰 수
* 찜하기 하트 아이콘

예시 mock data:

1. 안동 전통 수제약과 세트 / 24,000원
2. 공주 알밤 디저트 세트 / 16,000원
3. 부산 수제 어묵 세트 / 19,000원
4. 제주 한라봉 잼 / 13,000원

일부 상품에는 BEST, 인기 등의 작은 badge를 사용할 수 있다.

### 전체보기

‘전체보기’를 누르면 현재 인기 지역상품 전체 리스트 화면으로 이동한다.

버튼은 반드시 실제 navigation 기능을 가져야 한다.

---

# 8. 지역별로 둘러보기

다음 섹션 제목은

## 지역별로 둘러보기

로 한다.

D1 레퍼런스 이미지처럼 각 지역을

**원형 대표 이미지 + 지역명**

형태로 표시한다.

예:

* 부산
* 강릉
* 전주
* 여수
* 경주
* 제주

형태로 구성한다.

지역이 많으면 가로 스크롤 가능하게 한다.

각 지역 이미지를 클릭하면 해당 지역의 상품 목록으로 이동한다.

예:

부산 클릭
→ 부산 상품 리스트

강릉 클릭
→ 강릉 상품 리스트

제목 오른쪽에는

**전체보기 >**

버튼을 배치한다.

---

# 9. 테마 기획전

화면 하단에

## 테마 기획전

영역을 만든다.

일반 상품 카드와 다르게 이미지와 색상을 적극적으로 사용하는 프로모션 카드 형태로 구현한다.

예시 테마:

* 부모님 선물 추천
* 여름 제철 상품
* 지역 디저트 모음
* 여행의 맛 다시 만나기

각 카드에는

* 대표 이미지
* 테마 제목
* 짧은 설명

을 표시한다.

각 카드를 누르면 해당 테마 상품 리스트로 이동한다.

제목 오른쪽에는

**전체보기 >**

버튼을 배치한다.

---

# 10. 상품별 탭

‘상품별’을 선택하면 상품 종류를 중심으로 콘텐츠를 보여준다.

예:

* 식품
* 간식/디저트
* 농수산물
* 전통상품
* 생활용품
* 여행기념품

지역별 화면과 기본적인 UI 디자인은 동일하게 유지한다.

---

# 11. 테마별 탭

‘테마별’을 선택하면 상품 대신 테마와 기획전을 중심으로 콘텐츠를 보여준다.

예:

* 부모님 선물
* 여행 후 다시 찾는 맛
* 지역 대표 디저트
* 계절별 제철 상품
* KTX 여행지 추천 상품
* 명절 선물
* 가성비 지역상품

이미지가 포함된 기획전 카드 형태로 보여준다.

---

# 12. 필수 인터랙션

시연영상에서 사용할 화면이기 때문에 다음 요소는 반드시 실제로 클릭 가능하게 구현해줘.

* 상단 검색창
* 검색 실행
* 지역별 탭
* 상품별 탭
* 테마별 탭
* 개인화 추천 상품
* 부산 상품 더 둘러보기
* 인기 지역상품 카드
* 인기 지역상품 전체보기
* 지역 카드
* 지역 전체보기
* 테마 기획전 카드
* 테마 기획전 전체보기
* 상품 찜하기 버튼

버튼인데 클릭해도 아무 반응이 없는 요소는 만들지 않는다.

# 13. mock data

현재는 시연용 프로토타입이므로 실제 백엔드 연결은 필요 없다.

다음과 같이 mock data를 분리해서 관리해줘.

* `recentTripRecommendations`
* `popularProducts`
* `regions`
* `themeExhibitions`
* `productCategories`

검색 기능도 이 mock data를 기준으로 작동하도록 한다.

예를 들어 검색어가 `부산`이라면

* region이 부산인 상품

을 검색결과에 표시한다.

검색어가 `어묵`이라면

* 상품명 또는 카테고리에 어묵이 포함된 상품

을 표시하도록 한다.

# 15. 디자인 방향

전체 디자인은 첨부한 D1 이미지의 쇼핑 서비스 분위기를 유지한다.

특히 다음 요소를 반영한다.

* 흰색 중심 배경
* 코레일 블루 계열 포인트 컬러
* 충분한 여백
* rounded card
* 상품 이미지 중심
* 한 화면에 과도한 텍스트 사용 금지
* 모바일 커머스 앱처럼 직관적인 정보 구조

그리고 검색창은 첨부한 검색결과 레퍼런스 이미지의 디자인을 최대한 참고해서 만든다.

단, 검색결과 화면에 있는

* 추천순
* 가격순
* 배송비순
* 도착 빠른순
* 배송비 포함 가격
* 역 픽업 가능

등의 필터 UI는 **D1 메인 화면에는 넣지 않는다.**

이 요소들은 검색결과 화면에서 사용하는 UI다.

---

# 16. D1 최종 화면 정보 구조

최종적으로 사용자가 D1에 들어왔을 때 다음 순서로 보여야 한다.

**쇼핑**

↓

**🔍 지역명 또는 상품명을 검색해보세요**

↓

**지역별 | 상품별 | 테마별**

↓

**지난 부산 여행, 이어서 쇼핑할까요?**

↓

**지금 인기 있는 지역상품 / 전체보기**

↓

**지역별로 둘러보기 / 전체보기**

↓

**테마 기획전 / 전체보기**

↓

**하단 네비게이션**

이 순서를 유지해줘.

---

# 17. 구현 완료 기준

다음 항목을 모두 확인해줘.

1. 코레일 메인에서 쇼핑 아이콘을 누르면 D1으로 이동한다.
2. D1 최상단 콘텐츠 영역에 검색창이 표시된다.
3. 검색창 UI가 첨부한 검색결과 레퍼런스와 유사하다.
4. 검색창에 실제 텍스트를 입력할 수 있다.
5. 검색 실행 시 검색결과 화면으로 이동한다.
6. 검색창 아래에 지역별 / 상품별 / 테마별 탭이 있다.
7. 기본 선택 탭은 지역별이다.
8. 탭을 누르면 실제 콘텐츠가 변경된다.
9. 최근 부산 여행 기반 개인화 추천 영역이 있다.
10. 인기 지역상품 영역이 있다.
11. 지역별 둘러보기 영역이 있다.
12. 테마 기획전 영역이 있다.
13. 각 전체보기 버튼이 정상 동작한다.
14. 상품 및 지역 카드를 클릭할 수 있다.
15. 하단 네비게이션이 기존 화면과 동일하게 유지된다.
16. 모바일 화면에서 레이아웃이 깨지지 않는다.
17. 기존 코레일 프로젝트의 디자인과 자연스럽게 연결된다.

새 프로젝트를 만들지 말고 현재 코레일 프로젝트 내부에 구현해줘.

기존 router, component, icon, style system을 먼저 확인하고 최대한 재사용해줘.

기존에 정상적으로 동작하는 다른 화면은 불필요하게 수정하지 말아줘.

구현 완료 후 변경한 파일을 확인하고 build 또는 실행 과정에서 오류가 없는지까지 검사해줘.
